りんっベルの小庭｜マッチ3畑 v0.1

概要
- りんっベルの小庭から派生した、マッチ3パズルの最小土台版です。
- 6×6盤面で、🔔 🌙 🐇 💌 🪨 の5種類を使います。
- 隣同士のピースを入れ替え、縦横3つ以上そろうと消えます。
- 消えたあと上から落ち、新しいピースが補充されます。
- 20手以内に目標スコア800を目指します。

今回あえて入れていないもの
- 白狼、プリンなどの特別枠
- 特殊ピース、爆弾、障害物
- 小庭本体との育成連動
- PWA対応
- ステージ選択画面

使い方
1. index.html をブラウザで開きます。
2. 盤面のアイコンを選び、隣のアイコンを選ぶと入れ替わります。
3. 3つ以上そろえば消えます。そろわなければ元に戻ります。
