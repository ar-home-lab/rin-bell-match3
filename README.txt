りんっベルの小庭｜マッチ3畑 v0.3

これは「りんっベルの小庭」地下畑のマッチ3パズル土台版です。

v0.3で追加したこと：
- ステージ選択画面
- クリア状況のスマホ内保存（localStorage）
- クリア済みステージの遊び直し
- 未クリアの先のステージは鍵つき表示
- 「ステージ一覧へ」ボタン
- 「進行をリセット」ボタン

ステージ設定：
1. 地下畑の入口
   - 6×6
   - アイコン：🔔 🌙 🐇 💌 🪨
   - 手数：20
   - 目標：800

2. ベルの畝を広げよう
   - 6×6
   - アイコン：🔔 🌙 🐇 💌 🪨
   - 手数：18
   - 目標：1000

3. 月明かりの広い畑
   - 7×7
   - アイコン：🔔 🌙 🐇 💌 🪨
   - 手数：22
   - 目標：1400

進行保存について：
- GitHub Pagesなど同じURLで開くと、クリア状況が端末のブラウザ内に残ります。
- ステージ1をクリアするとステージ2、ステージ2をクリアするとステージ3が解放されます。
- クリア済みステージは、ステージ選択からいつでも遊び直せます。
- 「進行をリセット」を押すと、ステージ1からに戻ります。
