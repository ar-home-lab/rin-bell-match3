## v0.6〜v0.7の追加ポイント

- ステージ6〜10を追加。
- 通常ピースとして `🧶` と `🌱` を追加。
- `🐺` と `🍮` は通常ピースにはしない。
- ステージ5クリア後のごほうび画面では、`🐺` と `🍮` は予告出演のみ。
- `🐺` は「5個以上そろえた時に生まれ、タップで周囲3×3を消す」特殊ピース候補。
- `🍮` は「手数＋3」特殊ピース候補。出現条件は未決定。

## v0.7 変更点

ステージ10が連鎖しにくすぎたため、難易度を調整しました。

- ステージ10の通常ピースを8種類から7種類へ調整
- ステージ10の手数を23から26へ増加
- ステージ10の目標スコアを2200から2050へ調整

🐺と🍮は引き続き特殊枠候補として温存しています。


## v0.7 仕様メモ：🍮特殊ピース

- 登場ステージ：ステージ6以降
- 出現条件：プレイヤーの1手で、同じ絵柄を4つ以上そろえた時
- 生成数：1手につき1個まで
- 効果：🍮をタップすると、手数が+2される
- 手数消費：🍮タップでは手数を消費しない
- 🍮は通常ピースではなく、マッチ判定には含めない

## 今後の候補

- v0.8以降で白狼の実装と、🍮込みの難易度再調整を検討
