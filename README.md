# りんっベルの小庭｜マッチ3畑 v0.5

りんっベルの小庭の地下に作る、絵文字アイコンのマッチ3パズルです。

## 現在の安定版

- バージョン：v0.5
- 状態：全ステージクリアごほうび画面＋白狼・プリン予告出演版
- 公開想定：GitHub Pages
- 操作：スマホ・PCのタップ/クリック

## v0.5でできること

- ステージ選択画面
- クリア状況保存
- クリア済みステージの遊び直し
- 未クリアステージの鍵つき表示
- ステージ1〜5
- ステージ5クリア後のごほうび画面
- 白狼 `🐺` とプリン `🍮` の予告出演
- ステージごとの盤面サイズ、手数、目標、使用アイコン切り替え
- 3つ以上の縦横マッチ
- L字や交差などで重なったマッチの同時消去
- 落下、補充、連鎖、スコア加算
- 有効手がなくなった時の「畑を整える」
- 進行リセット

## v0.5の追加ポイント

- ステージ5クリア後に「地下畑、今日のぶん完成！」のごほうび画面を表示。
- 白狼 `🐺` とプリン `🍮` が特別枠の予告出演として登場。
- まだ通常ピースでも効果つきでもなく、次回以降の特別枠候補として顔見せだけ行う。
- 全ステージクリア済みの時、ステージ選択画面の進行表示も専用文言に変更。

## v0.4系で整えたこと

- ステージ4で `✨` が登場。
- ステージ5で `🕯️` が登場。
- 手数切れでクリアできなかった時の案内を、「もう一度」で再挑戦する文言に変更。
- ゲーム終了時は「畑を整える」ボタンを非表示にし、迷わず同じステージをやり直せるように調整。
- マッチ解決中の盤面暗転を防止。

## アップロード方法

GitHub Pagesで更新する時は、zipを解凍して以下のファイルをリポジトリ直下へ上書きします。

```text
index.html
style.css
script.js
README.md
README.txt
```

`README.md` がメイン説明です。`README.txt` は案内用です。
