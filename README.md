## 遊び方

隣同士のアイコンを入れ替えて、縦か横に3つ以上そろえる。
目標スコアに届いたらステージクリア。
クリア済みステージはいつでも遊び直せる。

## 特殊ピース

ステージ6以降で登場する。

- 🍮プリン：同じ絵柄を4つ以上そろえると生まれることがある。タップすると手数+2。手数は減らない。
- 🐺白狼：同じ絵柄を5つ以上そろえると生まれることがある。L字・T字も対象。タップすると周囲3×3を消す。手数は減らない。

1手につき特殊ピース生成は1個まで。5つ以上そろえた時は🐺が優先。
🍮と🐺は通常ピースではなく、マッチ判定には含めない。

## 保存について

クリア状況は、この端末・このブラウザだけに保存される。
別のスマホやPCの記録とは混ざらない。
同じ端末・同じブラウザで遊ぶ場合は記録を共有する。
