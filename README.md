# りんっベルの小庭｜マッチ3畑

「りんっベルの小庭」の地下に作った、絵文字アイコンのマッチ3パズルです。  
ベル・月・月兎・手紙・小石をそろえて、小庭の地下畑を耕します。

## 現在の安定版

**v0.3.1 / README整理版**  
ゲーム内容は **v0.3（ステージ選択＋クリア保存版）** と同じです。  
この版ではREADMEを整理し、現在地と今後の予定を分かりやすく残しました。

## できること

- 6×6または7×7のマッチ3パズルで遊べる
- 隣同士のアイコンを入れ替えられる
- 縦・横に3つ以上そろうと消える
- L字型や4つ以上のマッチもまとめて消える
- 消えたあと、上からアイコンが落ちて補充される
- 連鎖・スコア・残り手数を表示する
- ステージをクリアすると次のステージが解放される
- クリア済みステージは遊び直せる
- クリア状況はブラウザ内に保存される
- 進行リセットでステージ1からやり直せる

## ステージ設定

|---|---|---:|---|---:|---:|
