## v0.8.1 特殊ピース仕様

### 🍮プリン特殊ピース

- 登場ステージ：ステージ6以降
- 出現条件：プレイヤーの1手で、同じ絵柄を4つ以上そろえた時
- 生成数：1手につき特殊ピースは1個まで
- 効果：🍮をタップすると、手数が+2される
- 手数消費：🍮タップでは手数を消費しない
- 🍮は通常ピースではなく、マッチ判定には含めない

### 🐺白狼特殊ピース

- 登場ステージ：ステージ6以降
- 出現条件：プレイヤーの1手で、同じ絵柄を5つ以上そろえた時
- 生成数：1手につき特殊ピースは1個まで
- 優先順位：5つ以上そろえた場合は、🍮より🐺を優先して生成する
- 効果：🐺をタップすると、周囲3×3の範囲を消す
- 手数消費：🐺タップでは手数を消費しない
- 🐺は通常ピースではなく、マッチ判定には含めない
- 🐺生成は、横5・縦5だけでなく、L字やT字でつながった5個以上のマッチも対象
- 🐺起動後の落下・補充で自然にそろった場合は消えるが、連鎖中の追加特殊ピース生成は抑制する
