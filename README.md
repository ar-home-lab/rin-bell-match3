# りんっベルの小庭｜マッチ3畑 v0.4.2

りんっベルの小庭の地下に作る、絵文字アイコンのマッチ3パズルです。

## 現在の安定版

- バージョン：v0.4.2
- 状態：ステージ4・5追加、新アイコン追加版
- 公開想定：GitHub Pages
- 操作：スマホ・PCのタップ/クリック

## v0.4.2でできること

- ステージ選択画面
- クリア状況保存
- クリア済みステージの遊び直し
- 未クリアステージの鍵つき表示
- ステージ1〜5
- ステージごとの盤面サイズ、手数、目標、使用アイコン切り替え
- 3つ以上の縦横マッチ
- L字や交差などで重なったマッチの同時消去
- 落下、補充、連鎖、スコア加算
- 有効手がなくなった時の「畑を整える」
- 進行リセット

## v0.4.2の調整ポイント

- 手数切れでクリアできなかった時の案内を「もう一度」で再挑戦する文言に変更。
- ゲーム終了時は「畑を整える」ボタンを非表示にし、迷わず同じステージをやり直せるように調整。
- 「畑を整える」は、プレイ中に有効手が少ない時・盤面をシャッフルしたい時のボタンとして維持。

## v0.4の追加ポイント

- ステージ4で `✨` が登場
- ステージ5で `🕯️` が登場
- 既存のクリア状況がある場合、ステージ3クリア済みならステージ4が開くように調整
- 画面上部のアイコン説明が、現在のステージの使用アイコンへ切り替わる

## アップロード方法

GitHub Pagesで更新する時は、zipを解凍して以下のファイルをリポジトリ直下へ上書きします。

```text
index.html
style.css
script.js
README.md
README.txt
```

`README.md` がメイン説明です。`README.txt` は案内用です。
